# ImageGallery
A full-stack Image Gallery application built with React, Node.js, Express, MongoDB, Multer, and Sharp. Upload, resize, optimize, and manage images with a modern responsive UI.

Features:
• Single and multiple image uploads
• Automatic image resizing and optimization
• Image metadata storage in MongoDB
• Responsive and modern UI
• File type validation and size restrictions
• Organized image management system
• RESTful API built with Express.js

Tech Stack:
Frontend:
- React.js
- Axios
- Tailwind CSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- Sharp

The project demonstrates full-stack development concepts including REST APIs, file handling, image processing, database integration, middleware usage, and frontend-backend communication.
